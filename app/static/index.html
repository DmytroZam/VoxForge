Connect VoxForge to Discord in 20 Seconds

  1. If not installed yet, click Install VB-Cable (1-Click) and confirm the driver installer (then click Refresh, or reboot if Windows prompts you).
  2. In VoxForge on the right: set Microphone to your real mic, and Discord Output to CABLE Input (VB-Audio Virtual Cable).
  3. Open Discord → Settings → Voice & Video and set Input Device to CABLE Output (VB-Audio Virtual Cable).
  4. Tip: turn off Krisp noise suppression in Discord (and set Input Sensitivity manually) so Discord doesn't gate out Autotune, Robot, Walkie-Talkie, or Broken Phone effects.
  5. Global hotkeys work over games: Ctrl+Shift+0..9 and Ctrl+Shift+K (808s) switch voices, Ctrl+Shift+M toggles voice FX on/off.
